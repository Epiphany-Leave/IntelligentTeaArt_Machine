OneNET 联网配置说明（真实凭据已移除）

请在自己的 OneNET 项目中准备：
- 产品 ID、设备名称：固件与微信小程序保持一致。
- 设备级 MQTT token：供 tea 的 ONENET_MQTT_TOKEN 使用。
- HTTP API 鉴权 token：供小程序的 auth_info 使用，不要与 MQTT token 混用。
- 生成 token 所需的用户 AccessKey / 设备密钥：只在受控本地环境或服务端保存。

如需使用本仓库的辅助工具，可将 04_Tools/config.example.ini 复制为同目录的
config.ini，再在本地填写 res、et、key 等信息。config.ini 和 Token.log 已加入
.gitignore；不要强制提交它们，也不要将生成的 token、日志或截图上传到仓库。
请自行确认工具来源可信后再使用。

固件 Wi-Fi 配置和心知天气 API key 的具体位置见根目录 README。
本文件不再保存任何 OneNET 或其他云平台的密码、AccessKey、设备密钥或 token。
小程序代码与本地存储不能安全隐藏 API 密钥；生产环境应由自己的服务端代理请求。
已公开过的凭据仍可能存在于 Git 历史中，请在对应平台撤销/重新生成，Wi-Fi 密码也应更换。
